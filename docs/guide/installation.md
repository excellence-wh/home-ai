# 安装

> 要求 Python >= 3.10

## 从 PyPI 安装（推荐）

```bash
pip install home-ai
# Or `uv add home-ai` for uv users
```

## 从源码安装

```bash
git clone https://github.com/excellence-wh/home-ai.git
cd home-ai
pip install .
# Or `pip install -e .` for editable mode
# Or `pip install git+https://github.com/excellence-wh/home-ai.git` for direct install
# Or `uv add git+https://github.com/excellence-wh/home-ai.git` for uv users
```

## AUR（Arch User Repository）

如果你使用 Arch Linux 或基于 Arch 的发行版，可以通过 AUR 安装：

```bash
yay -S python-mijia-api
```
